# Console commands and CVars

Everything the running client lists in its console, from the client's own command list (`ConsoleGetAllCommands`): build 70790, interface 16001, exported 2026-11-05 13:35:56. 1878 entries, sorted into 32 topics.

Search with your browser's find (Ctrl+F). In game, open the console with `/console enable`, then the ` or ~ key; change a CVar with `/console <name> <value>` (or `/run SetCVar("<name>", value)`), and read one with `/run print(GetCVar("<name>"))`. "Default" is the value a CVar resets to; a CVar with no default holds saved state (a counter, a last-seen flag) rather than a setting. Your own current values are not listed: they differ per install.

The game's own categories are too coarse to browse (graphics options sit under "Default"), so these topics are chosen by name, using the rules in [`scripts/console-groups.json`](../scripts/console-groups.json). A setting in the wrong place is a one-line change there. Generated by `scripts/generate-console-docs.ps1` from a `WowApiExport` dump; do not edit this page by hand.
