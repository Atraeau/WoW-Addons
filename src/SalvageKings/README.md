# Salvage Kings

Raid loot via Salvage Kings on a transparent, tamper-evident ledger, for WoW: Forever.

Derived from the classic Suicide Kings strategy; named for the bottom-of-the-list
"salvager" role. Status: **Phase 0 scaffold** (module stubs only). Design lives in
[`docs/salvage-kings/`](../../docs/salvage-kings/): manifesto, rationale, design journal.

The previous prototype is kept in `archive/SalvageKings-legacy/` for reference.
